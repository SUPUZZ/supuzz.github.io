I ordered that Premium set of dinosaur-themed interlocking bricks to play with my 24mo granddaughter. She loves building stuff with other interlocking blocks, so I was looking for something a little different. This set comes in a nice carrying/storage case. The lid holds on tight, and it has a carrying handle. The set doesn't include a user's manual, but it's pretty self-explanatory. There are twelves interconnecting rectangles that you can use for the base platforms--either one big base of several smaller bases. Then the other pieces can be added on top of those. There's a variety of different parts to build a lot of different configurations. The pieces fit together so that it's never the same way twice--almost all of them can be joined in multiple ways. The pieces aren't too small, making it easy for little kids to hold onto the pieces while building. You can build simple trees all the way up to tall, elaborate trees. Other parts include logs, bones, dinosaurs, flowers, and butterflies. Kids can use their imaginations to assemble many different arrangements, and there's enough pieces so that more than one child can play with the set at once. This is a fun set to play together with my granddaughter. The price is comparable to similar sets.
