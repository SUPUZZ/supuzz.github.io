A few useful answers.

How many pieces are in the starter set?

The L1 set contains 38 pieces. Its package-content image shows the bases, stems, decorative elements and octopus.

Does this version include a storage box?

A storage box is not listed for the L1 version. The larger 136-piece L3 set includes one.

Can I add to the set later?

Yes. It belongs to SUPUZZ’s compatible nature-themed building collection. Additional ocean, ice and forest sets are sold separately.
